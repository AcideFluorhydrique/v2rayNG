Forkray 是 <a href="https://github.com/2dust/v2rayNG">v2rayNG</a> 的分支。v2rayNG 是 Android 上的 V2Ray 用戶端，支援 <a href="https://github.com/XTLS/Xray-core">Xray 核心</a>。Forkray 跟進上游 v2rayNG 的每一個版本，保留其所有功能與設定。

<b>與 v2rayNG 的差異</b><ul><li>完全在公開的 CI 上從原始碼建置，包括上游以預先編譯的程式庫形式下載的 Xray 核心。每個版本都會公開所用的確切原始碼、工具鏈與校驗碼，任何人都能重新建置並逐位元組比對。</li><li>使用獨立的應用程式 ID，可與 v2rayNG 同時安裝，不會取代它。</li><li>沒有應用程式內的更新檢查（由 F-Droid 用戶端負責更新），也沒有推廣連結。</li><li>絕不默默改為直接連線。代理失敗時，v2rayNG 會直接以你的真實 IP 取得訂閱等資料，即使在背景也是如此。Forkray 在未連線時略過背景更新，需要直接連線時會告訴你，並在不經代理重試之前先徵求你的同意。</li><li>路由資料庫由 <a href="https://github.com/AcideFluorhydrique/forkray-geodata">forkray-geodata</a> 中採用自由授權的來源建置，而非下載預先編譯的檔案。</li></ul>
<b>Geoip 與 Geosite</b><ul><li>內建的 geoip.dat 與 geosite.dat 來自 v2fly/domain-list-community、gfwlist、china-operator-ip、DB-IP Lite 以及各電信業者公布的位址範圍。IP Geolocation by <a href="https://db-ip.com">DB-IP</a>.</li><li>它們位於 <tt>Android/data/io.github.acidefluorhydrique.v2rayng/files/assets</tt>（部分裝置上的路徑可能不同）。</li><li>下載功能會改從 <a href="https://github.com/Loyalsoldier/v2ray-rules-dat">Loyalsoldier/v2ray-rules-dat</a> 取得較大的規則清單；代理執行時會透過代理下載。</li></ul>
