Forkray 是 <a href="https://github.com/2dust/v2rayNG">v2rayNG</a> 的分支。v2rayNG 是 Android 上的 V2Ray 客户端，支持 <a href="https://github.com/XTLS/Xray-core">Xray 内核</a>。Forkray 跟进上游 v2rayNG 的每一个版本，保留其全部功能和设置。

<b>与 v2rayNG 的区别</b><ul><li>全部在公开的 CI 上从源代码构建，包括上游以预编译库形式下载的 Xray 内核。每个版本都会公布所用的确切源代码、工具链和校验和，任何人都可以重新构建并逐字节比对。</li><li>使用独立的应用 ID，可以与 v2rayNG 同时安装，不会替换它。</li><li>没有应用内更新检查（由 F-Droid 客户端负责更新），也没有推广链接。</li><li>绝不悄悄改为直连。代理失败时，v2rayNG 会直接用你的真实 IP 获取订阅等数据，即使在后台也是如此。Forkray 在未连接时跳过后台更新，需要直连时会告诉你，并在不经代理重试之前先征求你的同意。</li><li>路由数据库由 <a href="https://github.com/AcideFluorhydrique/forkray-geodata">forkray-geodata</a> 中采用自由许可的来源构建，而不是下载预编译文件。</li></ul>
<b>Geoip 与 Geosite</b><ul><li>内置的 geoip.dat 和 geosite.dat 来自 v2fly/domain-list-community、gfwlist、china-operator-ip、DB-IP Lite 以及各运营商公布的地址段。IP Geolocation by <a href="https://db-ip.com">DB-IP</a>.</li><li>它们位于 <tt>Android/data/io.github.acidefluorhydrique.v2rayng/files/assets</tt>（部分设备上路径可能不同）。</li><li>下载功能会改从 <a href="https://github.com/Loyalsoldier/v2ray-rules-dat">Loyalsoldier/v2ray-rules-dat</a> 获取更大的规则列表；代理运行时经由代理下载。</li></ul>
源代码与问题反馈：<a href="https://github.com/AcideFluorhydrique/v2rayNG">github.com/AcideFluorhydrique/v2rayNG</a>。共有功能的文档请参阅 <a href="https://github.com/2dust/v2rayNG/wiki">v2rayNG wiki</a>。
